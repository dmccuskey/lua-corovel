## Basic Async TCP ##

A 2015 example from DMC Corona Library, run unmodified under Corovel.


## Status ##

It doesn't run as is: it requires `lua_sockets` and `lua_utils`,
old module names that are in no current repository (the
sockets library is now [dmc-sockets](https://github.com/dmccuskey/dmc-sockets)),
and it connects to `docs.davidmccuskey.com`, which is gone. Kept for
reference; see Known Issues in the main README.
